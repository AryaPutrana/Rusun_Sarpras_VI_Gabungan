🔴 CRITICAL ISSUE #1: USER ENUMERATION VIA ROLE CHECK
───────────────────────────────────────────────────────────────
Location: AuthController.php:59-67
Severity: CRITICAL

DESCRIPTION:
Login method queries database and checks user role BEFORE authentication.
Different error messages reveal if email exists:
  - Valid email, invalid role: "Akun Anda tidak memiliki akses"
  - Invalid email: "Email atau password salah"

IMPACT:
Attackers can enumerate registered email addresses for targeted attacks.

FIX:
Move role check AFTER Auth::attempt(). Always return generic error.

Code change needed:
  1. Remove lines 59-67 (pre-auth role check)
  2. After successful Auth::attempt(), check user role
  3. If invalid role, logout and return generic error
  4. Use same error message for all failures
