🔍 ROOT CAUSE ANALYSIS
═══════════════════════════════════════════════════════════════════════════════

Problem:
The WithdrawalController was using incorrect relationship chain:
• Used: 'inventory.items.item' (3-level deep)
• Reality: Withdrawal model has NO 'inventory' relationship
• Correct: 'items.item' (2-level deep)

Model Relationships (Correct):
┌───────────────────────────────────────────────────────────────────────────┐
│ Withdrawal Model (app/Models/Withdrawal.php):                            │
│                                                                           │
│ 1. items()         → hasMany(WithdrawalItem::class)                      │
│    Purpose: One withdrawal has many withdrawal items                     │
│                                                                           │
│ 2. rusun()         → belongsTo(Rusun::class)                             │
│    Purpose: One withdrawal belongs to one rusun                          │
│                                                                           │
│ 3. withdrawnItems() → hasManyThrough(Item::class, WithdrawalItem::class) │
│    Purpose: Get all items through withdrawal_items pivot table           │
│                                                                           │
│ NO 'inventory' relationship exists! ❌                                    │
└───────────────────────────────────────────────────────────────────────────┘

Relationship Chain:
┌───────────────────────────────────────────────────────────────────────────┐
│ WRONG (3-level):                                                          │
│ Withdrawal → inventory → items → item                                     │
│              ^^^^^^^^^ (doesn't exist!)                                   │
│                                                                           │
│ CORRECT (2-level):                                                        │
│ Withdrawal → items → item                                                 │
│              ^^^^^   ^^^^                                                 │
│         WithdrawalItem  Item                                              │
└───────────────────────────────────────────────────────────────────────────┘
