```php
public static function storeUploaded(?UploadedFile $file, string $directory): ?string
{
    if ($file === null) {
        return null;
    }
    
    try {
        $path = $file->store($directory, self::EVIDENCE);
    } catch (Throwable $exception) {
        report($exception);
        return null;
    }
    
    return is_string($path) ? $path : null;
}
```

✓ STORAGE: CORRECT
  - Null check for file
  - Exception handling with logging
  - Returns null on failure (handled by controller)
  - Stores to 'evidence' disk (private storage)
