│ 4. Check logs: Auth::attempt succeeded, then logout happened                 │
│                                                                              │
│ CURRENT CODE (VULNERABLE):                                                   │
│ ```php                                                                       │
│ if (Auth::attempt($credentials, $remember)) {  // Line 53 - Auth first      │
│     $request->session()->regenerate();                                       │
│                                                                              │
│     if (!in_array($request->user()->role, ['admin', 'petugas'])) {          │
│         Auth::logout();  // Line 58 - Too late, already authenticated!      │
│         return back()->withErrors(['email' => 'Unauthorized role']);         │
│     }                                                                        │
│     return redirect()->intended('/dashboard');                               │
│ }                                                                            │
│ ```                                                                          │
│                                                                              │
│ EXPECTED BEHAVIOR:                                                           │
│ Role should be validated BEFORE authentication. Invalid role users should    │
│ never receive a session or appear in Auth::user().                           │
│                                                                              │
│ ACTUAL BEHAVIOR:                                                             │
│ Auth creates session → role check → logout cleanup                           │
│                                                                              │
│ ROOT CAUSE:                                                                  │
│ Auth::attempt() on line 53 runs before role check on line 56                │
│                                                                              │
│ SUGGESTED FIX:                                                               │
│ Pre-validate role by querying User table BEFORE calling Auth::attempt()      │
│                                                                              │
